GrokfMRI

Memory Observatory for Grok — see how /flush, /remember, and /dream accumulate across your projects, without leaving your machine.

What it is

A read-only Next.js dashboard that parses Grok’s experimental memory store (~/.grok/memory/) and turns it into a timeline, workspace cards, system health, and an activity scan chart.

flush session-end remember dream

What it is not

  • Not a replacement for Grok’s /memory browser
  • Not a cloud app — no Vercel deploy of your memory contents
  • Does not write to memory or scrape full chat transcripts

Run it

Requires Node and Grok memory enabled ([memory] enabled = true in config).

npm install && npm run dev → http://127.0.0.1:3000
